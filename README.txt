HEMA & NITISH — WEDDING INVITATION

Everything is inside ONE folder:

Hema_Nitish_Wedding_Simple/
  index.html
  style.css
  script.js
  couple.png
  wedding-music.mp3  (optional)

To run:
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Right-click index.html → Open with Live Server.

On mobile:
Run Live Server on your computer and open its network URL on your phone while both are on the same Wi-Fi.

Optional music:
Put a file named wedding-music.mp3 beside index.html.
